# SeBot

ROS2 programming instructions for the SeBot robot, 28.5.2025, for the OpenUGV project's ROS2 mobile robot workshop.

The actual instructions are written in markdown files. The corresponding ready-made code (ROS2, Arduino, and WWW) can be found in the repository's `code` folder.

For SeBot, there is a suitable image file for Raspberry Pi 5, which can be written to a MicroSD memory card. The image contains a ready-made ROS2 environment and other necessary files and programs for this exercise. The file is stored in the OpenUGV project's Teams group (requires access rights from SeAMK). If you do not have access to this image file or want to do the exercise on another machine, you can install the ROS2 environment yourself using the `apt install` command through Ubuntu's package distribution. Instructions for this can be found in Material 0.

If you want to print your own SeBot base, the STP model and PDF dimension drawing can be found in the SeBot folder. Note, however, that for the purposes of this exercise, the shape of the base plate is very flexible, and the robot can be built, for example, in a sufficiently sturdy plastic box.
